# 下一阶段研究决策

**建议保留 B 与 H150 为冻结对照，下一阶段优先研究由状态和个体差异决定的受约束协调；不继续把某一组 H150 常数调成“通用患者解”。本轮到工作包 A 为止。** 这是一项研究方向建议，未启动 P1、工作包 B、Q-learning、RL、Neural Q 或参数搜索。

## 决策依据与证据等级

【PHYSICAL_LEVEL1】质量和腿长变化的多个患者保持了降力及完整资格，说明 H150 的有效性并非只限原 reference Human。与此同时，预注册低刚度患者 P05 的 H150 虽降低完整 J_F，却违反原膝最大速度、加速度 p95 和 excursion 非劣门；B 在该条件下仍有合格任务、安全与执行资格。完整队列结果及所有其他失败以 `REPORT.md` 和 `CROSS_PATIENT_QUALIFICATION.json` 为准。

【PHYSICAL_LEVEL1】即使 P00 通过原 motion 门，H150 也会增加膝局部终末下冲和力矩积分。全任务 excursion、局部下冲、最终 endpoint 与 tracking 是不同量。把奖励压缩成 J_F，容易把这些代价隐藏在正收益中。

【PHYSICAL_LEVEL1】高刚度患者 P06 的 B 完整通过，而 H150 因原 `KNEE_REFERENCE_MUST_BE_CONSTANT` 前提不满足中止。固定 RETURN slot 5 并不自动保证所有患者都满足终末意图的适用前提。该部分轨迹没有完整 J_F 或 gain；它提供的是执行适用性失败标签，不能作为高收益样本。

【PHYSICAL_LEVEL1】最终队列为 10 个完整有效配对、8 个 H150 完整资格通过。高阻尼 P08 降力 2.363384%，但膝 excursion 增加 0.528144°，超过原 0.5° 门；低刚度复合 P10 也因同一参考前置条件中止。高刚度复合 P09/P11 则通过。因此质量、刚度或阻尼的单一阈值都不足以概括已观察的适用边界，未来方法应处理参数组合与到达状态。

【MODEL_IMPLEMENTATION_FACT / MECHANISTIC_HYPOTHESIS】原模型存在髋膝惯性、姿态重力及有限刚度 cuff 耦合。H150 终末膝参考恒定时真实膝仍在运动，这支持把末端入口状态及估计动力学纳入决策；它不证明任一 H150 单组件是失败的唯一原因。当前比较是完整策略组合，没有同入口组件消融。

## 最值得学习的个体差异

应优先使用合法可获得的有效几何、cuff 力臂、估计动力学组合系数、残差及可信度，配合当前 q/dq、瞬时与近期 tracking、phase/elapsed、近期 force/moment、请求 source age 和执行状态。末端尤其需要膝是否仍在运动、髋是否尚未制动、距离已签发终末参考的误差，以及原准入/证书是否支持候选意图。

当前 commissioning 能在不同患者形成不同 belief，这属于冻结 B 自带机制。beta 估计偏差与整体预测误差不能等同，原模型还包含状态 residual。应先检验可辨识性和状态充分性，不能把生成器的真实质量、刚度、阻尼、native q/dq 或未来结局放入在线 STATE。

【INSUFFICIENT_EVIDENCE】本轮没有 P1 对照，不能确认精确患者模型是否能消除失败，也不能认定原模型失配是主要障碍。若下一阶段先做模型诊断，应按 `P1_PROTOCOL.md` 对 B/H150 同等提供已知参数，并将 oracle 参数假设与真实标定严格分开。

## 最值得研究的协调动作

动作应仍通过原安全执行体系：选择 B 或有条件启用协调；决定是否应用髋终末延时、OUTBOUND suffix 延时、早期 RETURN 时序调整及已定义的小姿态协调。动作范围、5 ms 量化、端点/剂量、certificate、current-state admission、splice、torque 和 fallback 规则应在下一阶段预注册后固定。

优先学习“何时不应启用某个协调意图”，再研究受限的幅度/时长调整。不能只因某患者降力更多就赋予其更多控制权限。需要完整任务评价，而不是仅奖励局部低力窗口。当前 B/H150 两臂数据只能支持有限的策略比较与失败标签，不能直接当作已覆盖连续动作空间的离线 RL 数据。

## 数据、目标和验证顺序

使用 patient identity 作为划分单位：P00–P08 用于未来开发；P09–P11 保留为未来拟合外患者。后者的本轮结局已公开，因此若后续方法设计使用这些结果，必须另建从未用于设计的患者身份作最终确认。禁止把同患者不同 prefix 随机拆成所谓跨患者测试。

首先审核 schema 的时间语义：紧凑状态中的 tracking 是针对已知 request/handoff reference 的误差；同步已发出 reference 的 tracking 需使用另存的因果对齐字段。安全退出证书事件与实际 fallback 命令分别处理。任何真值标签与在线特征应有明确防火墙。

之后再建立患者级评价：完整任务与绝对安全先作为硬资格，执行一致性独立核验；报告 J_F、moment、各关节 tracking、局部下冲、excursion 和运动负担。新运动目标若需加入局部终末下冲，必须作为新的前瞻性协议，不能回写本轮原资格。最后用新患者与新的合法 prefix 检验泛化，同时保留匹配 B 和冻结 H150。
