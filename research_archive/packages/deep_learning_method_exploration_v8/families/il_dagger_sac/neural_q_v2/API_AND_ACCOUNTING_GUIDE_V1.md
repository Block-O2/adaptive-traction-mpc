# Source-only API与计数

没有训练入口被执行，也没有已实例化model/checkpoint。两个learner源仅AST检查，未import；NumPy在函数内lazy import。当前只有JSON/source可得性审计（V1 metadata join失败、V2完成），0模型调用。数学fixture计划不是授权，不自动运行。

`terminal_head_candidate_v1.initialize(...)`未来构造一个独立stream的LINEAR或TANH16及其Adam m/v，需精确main call authorization/source/data/menu/feature/contract SHA、训练row manifest和已登记local stop。维数25或39，真实只能冻结SAC64；synthetic scope不能改名real。`loss_and_gradient`做原observed action监督；`step`只在私有copy成功且截止未到时提交参数/Adam状态。异常带`neural_q_private_consumed_work`供主runner记录已消费forward/gradient/private数组工作，不能把未发布计算从账删除。

`predict`一次输出N×5个同目标值，risk为uncalibrated sigmoid，成本还原原单位，无qualification。`snapshot/restore`保存全部数组、Adam、计数、初始化RNG状态、row/source/normalizer身份；fullbatch训练不再draw随机数。restore仍是独立实际API/构造成本，要单记，不能当初始化0等于没建立对象。

`ridge_reference_candidate_v1.fit`只拟合RETURN/JF_CENTERED/JM_CENTERED，五个action的实际观测方程、bias不正则；缺action时对应head=None，不补label。实际code只有NumPy solve，source/math residual还待fixture。Ridge risk受限rule明确复用同seed LINEAR logistic风险，不能宣称ridge训练了BCE风险模型。

`choose_from_return_and_risk`只接受return/risk五数与两种预登记selector；不接JF/JM、case、真实原门。成本预测再好也不会因任意加权改变policy。预测风险没有校准保证，fallback只是原B权限，不代表学习成功。未来物理API必须再绑定实际OUT0 payload/source profile，经原A3 scoped causal准入或同等经审25D提取，不能只靠qa=True授权执行；本source无派发、控制器、环境或文件写入。

计数按head API而非一个大bundle含糊相加：一次训练step含一次forward和一次gradient、一组Adam参数更新；action outputs=5N，但observed监督样本=N。regression/risk互不共享梯度。initialize输出normal随机标量数与bit-generator状态，不把正态输出个数冒称底层uniform draw次数。clip激活、source/time拒绝、未完成API entry与completed、failed private work都由未来主runner额外显式记录。

25D GateR拟468初始化/93600 Adam steps及同数训练forward/gradient，39 ridge fit/195 solve，2700 learned predict/75 ridge predict；没有额外twin或actor模型。所有数量是提案，不是实际执行账。模型参数130/501；若另批39D则200/725。input normalizer13、centered cost目标normalizer26，其他固定scale0fit。parent/early/final各保存，final固定、3seed都保留，禁止best/自动重训。

当前没有可执行CLI拟合runner，也没有main real-fit authorization，避免把source合同直接当训练批准。主审后应另写单次owner runner，绑定实际binary/NumPy/module/source/data/AST/CPU/RSS/deadline及所有拟议API；该runner由root review后才能启动。原研究venv已存在，无安装依赖。
