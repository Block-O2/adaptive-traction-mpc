# 原clearance包络的解析机制核验

本分析新增物理尝试和native积分均为0。没有修改控制器、几何、安全阈值或scorer。

原袖套下边界可写为 `gap(q)=z_cuff(q)-r*sqrt(1-a(q)^2)-z_bed-L*abs(a(q))`，其中 `a` 是袖套轴的世界竖直分量。前三项在本次近水平姿态附近光滑，最后的端点最小值在 `a=0` 不可微。

|实际失败案例|原10μs差分曲率 m/s²|端点最小值项|光滑项|同分支解析曲率|跨分支临界h μs|
|---|---|---|---|---|---|
|CORE_C_019|-1432.356195|-1432.356216|0.000021|0.000021|0.943912|
|PPO_SCRATCH_TRAIN_0009|-449.597641|-449.568162|-0.029479|-0.029479|4.159603|

在精确切换点，若轴竖直速度非零，端点项的中心二阶差分约为 `-2L*abs(a_dot)/h`。已观察事件处并非精确零点；h小于表中跨分支尺度后回到单分支，不能称这些固定偏置状态在h→0时发散。极小h还会出现浮点抵消。

这解释原控制器计算中的大负曲率及随后的力矩修正，不把该数值称为真实Human加速度，也不删除因此产生的native jerk。原函数因果重放、真实冲量和后续运动失败另有各自证据。

待验证的下一步：`min(gap_a,gap_b)>=margin` 与同时满足两个端点gap约束代数等价。可在独立协议中研究两条光滑分支的因果反馈是否避免跨分支二阶差分，同时保持相同几何、阈值和原scorer。此处未实现或实测该替代方案，不声称安全或收益已证明。
