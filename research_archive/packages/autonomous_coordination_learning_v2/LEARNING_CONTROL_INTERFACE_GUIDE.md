# 学习与控制接口：这轮究竟改变什么

机器人通过 cuff 带动被动下肢。学习器或上层优化器决定的是“髋膝怎样配合走完运动”，原控制器继续负责跟踪、分配机器人力矩和执行安全检查。

## 输入来自哪里

实际控制仍读取当前估计的髋膝角度与速度、已签发参考、cuff 测得的力/力矩、当前阶段、时间和 commissioning 得到的 Human 模型估计。候选执行前的规划器可以读取已经完成的历史运动。这轮名义代理使用冻结的历史强固定参考（H150族内的旧二维最优点）与估计模型，输出的是名义负荷近似；它没有提前看到新候选的真实 Human 运动。

当前主比较固定一个合法 prefix，因此每个方法面对同一个完整父状态。scratch PPO 在这个固定上下文输出一个完整的高层协调计划；每条真实任务是一集、一个 RL 决策。开发条件每个fork约69,260次新增native积分；含继承前缀的完整档案约116,320步，仍只有一个高层学习样本。这并未检验跨状态策略或多步 Q/Value 的能力。

## 输出是什么

A1 仍输出旧局部二维参数：分别微调去程、回程的髋膝相对进度。换成和/差坐标后，允许的真实运动集合保持相同；若搜索更快，只能归因于坐标和优化行为。

A2 输出 8 个在 [-1,1] 内的参数，以H150为家族基础、主比较以已复现的强固定方案为中心，增加以下控制权限：

|参数|容易理解的意思|最大设计幅度|
|---|---|---|
|去程/回程共同路径，各1个|中间姿态时，两关节一起多走或少走一点|每个模式 .30° 乘局部包络|
|去程/回程相对路径，各1个|让髋提前、膝落后，或反过来|每个模式 .30° 乘局部包络|
|去程/回程局部时长，各1个|把中间一段参考安排得稍长或稍短|±8%，按5ms参考网格取时长|
|去程/回程通过速度，各1个|经过中间姿态时，保留更多或更少速度|±12%|

共同与相对模式叠加时，单关节偏移可达 .60° 乘包络。实际签发可能被原门拒绝，设计幅度不等于实际权限。端点、HOLD 和既有终末修复规则保留。参数不是任意 motor torque，也不是每个数学样条系数都能独立进入执行。

## 如何成为参考与真实运动

1. 上层输出本次完整运动的参数，并在物理 START 前保存模型、参数和预测身份。
2. 每个原生决策请求结合当前因果状态，先生成原 H150族及强固定中心的目标与参考。
3. 新接口只在内部 waypoint 调整目标、时长和通过速度；原 `_evaluate`、固定时长 quintic、完整连续路径证书与其它原检查重新评价这个候选。
4. 通过的计划仍需经过 lifecycle、activation、当前状态 admission 和 splice。未通过的 proposal 使用原认证续行，拒绝原因保留。
5. governor 按原规则推进参考；FAST 反馈与 allocator 把跟踪需求转成机器人 torque。
6. MuJoCo 中机器人通过 cuff 接触力/力矩影响被动 Human。最终真实运动与参考不同，必须单独检查 tracking、native 速度/加速度/jerk、完整任务和原 motion 门。

保留 proposal、accepted/rejected、activated、issued reference、command receipt、applied torque 和 native Human 的身份链。接口审计比较的是实际签发参考、实际施加 torque 和真实运动是否响应，不能只看参数变化。

## Learning 和 PPO 各在做什么

Learning 辅助搜索尝试补充名义模型遗漏的闭环响应和运动余量。训练标签来自已经完成的仿真任务，整条任务分组，不能把相邻时间点当独立测试。原始 Human motion 余量是本轮仿真评价反馈，尚不是可在患者上直接获得的新传感器能力。预测更准、排序更准、选择改变、执行后真实更好分别评价。

PPO 使用新建的 8 维 Gaussian actor，经 tanh 转成合法参数，记录变换后的精确采样密度。每个 batch 使用同一冻结行为策略；所有本 batch 原任务完成后再作 Adam 更新。旧动作语义的 PPO checkpoint 不用于“继续训练”。如采用教师初始化，会单独标记教师来源与额外数据成本。

所有收益最终由原完整任务 scorer 决定。降低 force 仍可能增加 moment 或运动负担；仿真合格也没有赋予在线5ms、硬件或临床资格。

## 本轮新增的参考响应学习分支

在固定上下文中，用已完成的共同17条运动历史，学习“8个协调参数经过真实执行链后，实际签发的参考会怎样改变”。学习标签只含过去的 q_ref/dq_ref/ddq_ref，不把新候选执行后的Human真值当输入。随后仍由原估计Human逆动力学和allocator给预测参考估计负荷，优化器输出普通8维参数，原MPC、安全证书与准入继续决定真实执行。预测曲线不会直接写进控制器。

这一分支与使用同17条历史直接拟合cost方向的传统响应面，在相同候选池中比较；测试总数上限4。它们都依赖多条已完成仿真历史，不能解释为患者两三次就学会。参考预测正确仍不能替代实际Human motion原门。

这里的8个有效模式不是“原18D之外又增加8个全局独立自由度”的证明。部分路径/速度模式可能与原18D可表达方向重叠；独立内部时长安排明确扩展了原最短时长接口。有限实际参考差分秩为8，只说明本轮局部干预有8个可辨方向。


## 参考合法之后，反馈仍会改变实际作用

新参考通过证书，并不意味着最终Human运动必然平滑。原FAST控制器还会根据当前因果估计与cuff观测，做加速度和clearance修正；修正后的广义力矩再由allocator变成机器人motor torque。因此一个合法计划仍可能引起真实加速度/jerk问题。

本轮CORE_C_019在接近水平的姿态遇到原圆柱clearance包络端点切换，差分曲率触发瞬时广义力矩修正，原native motion门拒绝了这个完整任务。这个反馈事件以原函数、已记录因果充分输入重放；没有关闭guard或改scorer。四个预登记时序干预另列结果。参考响应模型只预测实签q_ref/dq_ref/ddq_ref，没有因此获得预测全部闭环反馈或真实运动的能力。见FAILURE_MECHANISM_ANALYSIS.md。
