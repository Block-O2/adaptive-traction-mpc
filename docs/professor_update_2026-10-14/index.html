01 / WHY WE CHANGED THE ARCHITECTURE · 2 MIN

从“跟踪既定轨迹”到“在线决定下一段”

固定参考能回答怎样跟踪，却不能直接回答怎样协调髋膝运动更省力。Stage 5 首先尝试 Goal-directed Torque MPC，再转向在线 Human waypoint。

外部固定整条运动

给定 q_ref / dq_ref / ddq_ref，底层估计和控制负责执行。这里只作为上一轮工作的衔接。

Goal-directed Torque MPC

面向 phase 目标选择 generalized action。Human-only 预测与 robot/interface 真实执行不一致；HOLD、RETURN 和完整 motion 合同暴露问题。

Online Hip/Knee Waypoint

从当前估计状态选择下一对关节目标；scheduler 生成可接入的一段运动，再由机器人通过袖套执行。

架构转变保留轨迹规划、真实接触、安全准入与 fallback。Stage 4 / High-ROM 不在本次重复汇报。

03 / CURRENT CONTROLLER B · 2 MIN

让运动收益有可核验的执行含义

估计 → 规划 → 准入

Commissioning 建立控制有效几何与动力学 belief；planner 选择 waypoint；scheduler/governor 生成 quintic；计算结束后在当前估计状态重新检查版本、phase、ROM、motion、clearance 和接续。

knee-to-cuff lever 可辨识不代表 shank length 与 cuff fraction 分别已知；commissioning_only 也不代表已实现重复间个体化。

40 ms bridge / 100 ms lifecycle

source age 从原测量开始计，不因返回或重试刷新。40 ms bridge 提供预先验证的短接续/停止通路；100 ms 限制 proposal 年龄。迟到或拒绝后进入合法 carry/stop 与 SAFE_FALLBACK_HOLD，再用新状态规划。

5 ms FAST 服务与 0.25 ms native physics 是不同时间尺度；strict55 是另一个历史 qualification 门槛。

Causal receipts：每个 native step 归属到实际 applied command 与 robot torque。科学仿真可核验有限同状态物理比较；host-clock 还须通过真实计算、提交年龄与时序资格，不能由科学模式替代。
04 / LEARNING ATTEMPTS · 3 MIN

先确认有值得学的动作，再讨论怎样学习

路线关键经验结论边界
Direct RL / SACscratch SAC 300k 未取得完整 phase 任务；DAgger 学生曾完成，SAC fine-tuning 又丢失能力。任务能力和安全接口仍是前提。anchored SAC 约14.486%改善主要减少过长 HOLD，不能与本页同时间协调收益排名。
E / offline teacher搜索可执行的协调运动，判断动作空间中是否存在收益。有限预算 best-known；不是全局最优或成熟个体化。
M2 / Linear Q在 B 合法 remaining-plan 选择处排序；旧同 Human 条件约6%–9% force 收益。固定候选池中 Q(s,p)=a(s)+b(p)，两 plan 比较时 a(s) 相消。mask/carry 改变不等于学会状态条件排序。
Neural Q32×32 网络可表达 state×plan；两个 test state 的 regret 为9.9306 N·s，linear 为1.6207 N·s。覆盖、ranking inversion 和监督合同不足；V_commit 与 V_replan 不自动等价。不能宣称 few-repetition adaptation。

各路线对应不同任务、时长、动作权限和验证分母，仅说明经验，不跨条件直接排名；早期96D SHORT MLP曾优于对应ridge，不概括为“所有神经网络失败”。

07 / WHAT WE NEED TO DISCUSS · 2 MIN

希望教授帮助确定的五个决策

中间髋膝轨迹允许变化多少？约15.2° phase-shape 差是否仍属于同一治疗任务？
工程平顺性与临床运动标准怎样对应？如何规定速度、加速度、jerk、剂量与 force/moment 的权衡？
是否扩展 B 的参考接口，允许 bounded common progress 与独立 waypoint velocity？
论文重点应放在控制架构、优质协调优化，还是 few-repetition learning？当前第三项尚未实现。
怎样迁移到更真实人体与硬件？需要哪些测量、接触模型、状态覆盖和实时资格证据？

建议先确定姿态自由度与运动质量标准，再冻结下一轮合法状态验证和接口迁移合同。
