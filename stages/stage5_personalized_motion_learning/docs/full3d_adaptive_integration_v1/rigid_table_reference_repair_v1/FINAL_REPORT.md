# DEV-D 固定硬桌面反馈参考修复：最终开发报告

**最终状态：`REFERENCE_REPAIR_PARTIAL`。** 本阶段修复了旧 commissioning 参考轨迹主动要求小腿／袖套穿过硬桌面的缺陷，并把同一几何合同扩展到 ACTIVE_RECOVERY 与任务的连续 quintic 段。新参考仍由可部署观测驱动，真实 CR12–柔顺袖套–Human V2 物理链完成执行；几何拟合和在线 beta／残差学习继续工作。但是，23 个可初始化的旧开发案例仍只有 5 个完成全程：两例真实袖套几何越界，11 例规划过期，另有任务速度或 waypoint 不可行。因而这不是当前域的完整控制器资格验证。

## 失效因果链和实际修改

旧固定 commissioning 关节路点在 `balanced_middle_r01` 的 2.535 s 首次要求小腿进入桌面（−0.094 mm），真实小腿 2.540 s 才进入；旧请求最深 −24.434 mm。`balanced_near_upper_current_rom_r02` 的旧请求小腿更达到 −53.708 mm，但其真实袖套在 0.030 s 已先越界，早于 2.325 s 的旧请求小腿穿桌。这说明“参考本身错误”和“极小初始间隙下的真实执行／支撑误差”是两个机制，不能合并为适应模型误差。

新组件对固定近端大腿、保守小腿、袖套、袖套横杆和转接件计算硬桌面间隙。Commissioning 以先前已发出的参考为 C² 连续起点，以最新估计的 Human q 调整下一路点；先保留原有信息性方向，再显式缩短／最小髋关节上抬修正，并对 ROM、速度、加速度与整个 quintic 路径做检查。尚未接受多姿态拟合时用已注册的先验／安装下界，而不把单次袖套测量误判成解剖髋高；袖套自身的因果实测位姿另行逐控制边界监测。没有调用隐藏真实 Human q 或病人几何选择动作。模型拟合后的 ACTIVE_RECOVERY、任务、HOLD、RETURN 使用同一个组合间隙合同，保留旧小腿安全检查；独立审计发现的负间隙门槛与采样间漏洞随后由仅 DEV-D 启用的非负门槛、1201 点加导数界连续段证书修正。旧默认模式、物理／动力学模型、beta 和残差更新律、任务 MPC 成本／候选、DEV-C 关闭状态、force/moment、ROM、100 ms 截止和零 value hook 未改变。详见 [设计与流程](DESIGN.md)。

## 代表性物理证据

[对齐轨迹与首个分歧](REPRESENTATIVE_RESULTS.md)中的图和原始记录显示：严格版 `balanced_middle_r01` 的请求／真实小腿最小间隙变为 +21.805/+15.685 mm，袖套变为 +24.418/+20.573 mm，且完成 commissioning 和 recovery；但任务后来因过期方案中止。`balanced_ordinary_r01` 从旧 `NO_FEASIBLE_WAYPOINT` 变成完成全程。近上界 r02 的计划袖套连续下界虽为 +0.042921 mm，真实袖套仍在约 0.030 s 穿零，并在 0.035 s 以实测 −0.017875 mm 正确停止；另一个膝主导案例在 5.955 s 以 −0.032834 mm 停止。袖套碰撞对在 MuJoCo 中未启用，这些是几何越界，不是袖套碰撞力读数。原本完成的 nominal 代表案例在新 commissioning 后的 RETURN 因保留的可部署间隙监视器中止，真实小腿间隙仍为正；该退化没有被隐藏。

## 旧案例开发回放，不是新鲜资格验证

原 24 个键中，v2 机械装配合同允许 23 个执行；`balanced_ordinary_r02` 的初始袖套 −2.513 mm，要满足 +0.1 mm 安装间隙需 +7.178 mm 髋高，超过已注册 +6 mm 范围，仍保留为无效生成案例，不用结果重抽。严格 DEV-D 在 23 个实际执行案例中：21 个完成 commissioning、几何拟合、主动恢复并进入任务；5 个完成 OUTBOUND–HOLD–RETURN；18 个失败，构成为 11 个 stale-plan、3 个 waypoint 不可行、2 个速度门限、2 个实测袖套越界。前一装配修复的不同版本组合为 23 个 commissioning、22 个任务进入、5 个完成；两组都不是独立新鲜统计验证，不能把 5/23 说成整体提升。

21 个有完整 5 ms 边界轨迹的案例中，评价侧真实几何重算未见请求或实际小腿／袖套负间隙；请求最小小腿／袖套 +14.603/+8.177 mm，实际 +7.418/+2.277 mm。**这些正间隙不包含两例提前停止的袖套越界。** 所有 23 例的原生 0.25 ms 大腿／小腿桌面接触监测峰值均为 0 N；这不证明碰撞禁用的袖套、横杆或机器人关节链路安全。21 个完成 commissioning 的案例全部接受了控制有效几何拟合，至少 353 采样、角度跨度 0.196–0.341 rad；任务阶段合计 324 次 beta 接受更新、9453 次残差更新。这证明信息和更新存在，不证明参数收敛。5 个完成案例的任务 q RMSE 分关节范围为约 0.418–0.730°、0.344–0.905°。

109 次任务高层规划计算：平均 62.708、median 73.510、p90 100.116、p95 106.218、p99 123.888、最大 124.615 ms。11 次超过未变的 100 ms 合同并拒绝激活，11 个案例因此中止；另 3 次正常不可行不是 deadline miss。更早的 V2 派生汇总误把这 3 次也算入“14 个超时”；保留错误文件并在 V3 以逐决策拒绝原因更正为 11。Commissioning 的 84 次段规划最大 5.238 ms。对同一几何公式的竖直分量等价计算把 121 点组合微基准 median 从 0.080 降至 0.059 ms，但没有消除端到端尾部，不能声称 100 ms 已合格。

21 个完整轨迹的全会话已记录实际袖套力／矩峰值最高 159.430 N／22.846 Nm，按实际执行区间累计力范数 244.167–870.909 N·s；两例早停没有完整会话力积分，不外推其数值。记录到的真实 Human 加速度违规标志和 ROM 违规步数均为 0；最高任务机器人力矩占限值 0.576。此处是仿真观测与注册工程门限，不是硬件或临床安全证明。详见 [完整开发回放](REGRESSION_REPORT.md)。
