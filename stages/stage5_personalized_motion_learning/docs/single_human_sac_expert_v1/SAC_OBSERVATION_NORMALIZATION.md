# Observation and normalization

All 55 feature names, causal sources and exact scale values are in JSON. Angle scales use 125-degree ROM; per-joint velocity and acceleration scales use frozen task limits; measured force uses 200 N, moment uses 20 Nm, effective-model beta uses 10 coefficient units, residual uses 20 Nm, geometry uses 1 m; clocks use task/phase/HOLD duration. No clipping or future/evaluation statistics. Coefficient-specific interpretation is effective dynamics rather than anatomical truth. Outliers are measured before formal freeze.
