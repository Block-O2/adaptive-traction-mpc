# WSL handoff — ordered no-change runbook

1. Clone or fetch `git@github.com:Block-O2/adaptive-traction-mpc.git` in WSL. Use branch `codex/learning-wsl-migration-v1`; do not merge it.
2. `git fetch origin codex/learning-wsl-migration-v1 && git switch --detach origin/codex/learning-wsl-migration-v1`. Compare `git rev-parse HEAD` to the exact pushed SHA supplied in the migration closeout handoff and `git ls-remote origin refs/heads/codex/learning-wsl-migration-v1`. A mismatch blocks benchmark.
3. From repo root verify `SOURCE_FINGERPRINTS.json` using the frozen 179-file source map in `docs/safe_fallback_execution_v1/FREEZE_v1.json` (Stage-5-relative doc paths are under `stages/stage5_personalized_motion_learning`). Run the bundled benchmark runner `--list --expected-head <SHA>`; it checks fingerprint and case hashes without simulation.
4. Create Python 3.10 environment and install dependencies per `WSL_ENVIRONMENT_BOOTSTRAP.md`; save `pip freeze`, OS/CPU/RAM/WSL/GPU/load metadata.
5. Check `import mujoco`, GPU/EGL availability if used, CR12 XML load and all referenced meshes. The XML and meshes are tracked in this branch.
6. Run `PYTHONDONTWRITEBYTECODE=1 python -m pytest -q -p no:cacheprovider stages/stage5_personalized_motion_learning/tests/safe_fallback_execution_v1/test_safe_fallback.py stages/stage5_personalized_motion_learning/tests/high_rom_v1/test_score_return_endpoint_v2.py stages/stage5_personalized_motion_learning/tests/wsl_migration_v1/test_portability.py` from repo root.
7. Run one no-change smoke case from repo root with `python stages/stage5_personalized_motion_learning/scripts/high_rom_v1/run_dev_case.py --plant-mode low_rom --case stages/stage5_personalized_motion_learning/configs/high_rom_v1/low_rom_regression_cases/balanced_ordinary_r01.json --output stages/stage5_personalized_motion_learning/results/wsl_migration_smoke_v1/low_ordinary --host-monitor-limit-s 300`. Label it **smoke**, preserve failure and do not count it among the 24 benchmark runs.
8. Only after these checks, execute the 24 ordered run IDs in `CROSS_HOST_BENCHMARK_V1.json`, using `python stages/stage5_personalized_motion_learning/docs/wsl_migration_v1/cross_host_benchmark_runner.py --run-one <run_id> --expected-head <SHA> --output-root stages/stage5_personalized_motion_learning/results/cross_host_benchmark_v1`. Use a distinct output directory per run. Each attempt counts even if it fails. No replacement or attractive rerun.
9. Preserve raw outputs and per-run records locally, including failed runs; report WSL host metadata and compare only valid matched data. Historical Mac rows are contextual and strict matched Mac reference is missing. Do not modify production before benchmark completion.

The 100 ms stale rule and Safe Fallback semantics remain fixed. The commissioning stale-command failure, 55 ms activation tail, RSS runtime qualification FAIL, and fresh49 FAIL remain unresolved. This package supports research-host migration only; no hardware or clinical use is authorized.
