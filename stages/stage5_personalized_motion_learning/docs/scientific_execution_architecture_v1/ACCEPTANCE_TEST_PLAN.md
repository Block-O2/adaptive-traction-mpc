# Acceptance gates for a subsequent implementation

No tests or simulations below were executed in this architecture audit. Use narrow unit tests first, then bounded development cases; no tuning, campaign or 30-repeat. Record exact source/config hashes, command, environment/library and thread settings, seeds, ordered events, full negative results and output paths before dynamic tests.

| Gate | Fixture / action | Required outcome |
|---|---|---|
| Determinism | Three scientific repetitions with fixed seed, initial state, config, worker/numerical environment | Identical integer step/event/request/version sequence, candidate selection, phase/dwell/score; bitwise identical native q/dq/torque/reference arrays on same host after excluding only named host metadata |
| Host-delay invariance | Baseline plus 100/200/500 ms injections, separately at snapshot/worker finish/receipt/validation/torque construction/prewrite/terminal; optional 2 s focused fixture | Same physical arrays/waypoints/scorer and transition identity as 0 ms; wall completion/profile grows. No fallback due only to delay; no logical/physical progress during barrier |
| No future leakage | Guard plant access from worker; mutate original input arrays after serialization; attempt injected epoch/model/phase/reference changes while pending | Worker sees original bytes only; attempted scientific mutation during barrier fails; mismatched receipt/write is rejected; no evaluation truth in payload |
| RSS two transactions | Receive suffix at S_k; execute bridge to deterministic handoff S_j; validate anew | Old source retained, fresh activation certificate bound to S_j, C2/geometry and simulated source horizon enforced; no blind equality bypass or restamp |
| Algorithmic fault | Infeasible planner, worker exception, invalid certificate and step/request-indexed timeout | Existing certified TASK fallback commits/stops/holds/replans where covered; no dwell in fallback hold; uncovered failure retained as abort; braking nonpreemptible |
| Realtime preservation | Fake-clock old/new differential tests with <100, exactly100, >100 ms, delayed receipt/write, fork, expiry, finalization | Same wall stepping, receipts, rejection reasons, fallback and metrics. Plan guards reject >=100. Command > boundary recorded as known defect; any separate correction explicitly authorized and tested |
| Command atomicity | Throw before write, during simulated write, and after successful write | No physics before valid write; failed write rollback; post-write failure accurately owns receipt; no relabel as unexecuted |
| Commissioning | Step mock plus one bounded moving fixture with 150 ms torque delay | Exactly 20 native steps per control interval, no held command extension, same torque law and causal sample sequence |
| Controller equivalence | Same immutable input fixture; then replay identical approved command sequence at identical simulation nodes through both adapters | Exact controller output and physical trajectory in same environment. Free-running realtime vs scientific need not match when application nodes differ; enumerate every scheduler difference |
| Scorer equivalence | Score same saved native trajectory/COMPLETE mapping independently with unchanged v2 | Entire v2 scientific JSON equals; host metadata separated; no interpolation or favorable endpoint choice |
| Terminal/timeouts | Delay RETURN checks; physical horizon boundary; phase/session timeout; delayed cleanup | Scientific host delay cannot defer/abort/advance COMPLETE; physical limits unchanged; no post-commit physics, task dwell or adaptation |
| Logical cadence | Instrument sensors, filter updates, adaptation, reference receipts and RNG | Correct grid/once-only updates; no duplicate observation updates; deterministic tie order; held sample timestamps unchanged |
| Resource interruption | STOP/cancel, worker crash/hang watchdog | Retain INCOMPLETE/exception provenance at frozen state; no successful truncated sample or algorithmic-failure substitution |
| Separation | Inspect dependency/dataflow and default mode | Wall profiler never drives scientific decisions, budgets, candidate ranking or physics; default realtime behavior unchanged; invalid mode rejected |

Exact comparison is the default for same-host repeats. If deterministic numerical libraries cannot produce bitwise equality, do not silently loosen tolerances after results: identify the cause, preregister operation-specific roundoff bounds and require identical discrete decisions. Cross-host equivalence is a separate study, with justified predeclared numerical tolerances; this audit supplies no invented universal tolerance.

Use bounded fixtures covering commissioning, nonzero-velocity RSS, fallback hold/resume and RETURN commit, including the retained failing commissioning mechanism. These are software/development validation, not robustness or hardware qualification. Scorer success alone cannot promote the new mode before delay and causality gates pass.
