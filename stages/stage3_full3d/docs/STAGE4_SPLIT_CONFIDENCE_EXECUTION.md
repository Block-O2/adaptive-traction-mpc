# Stage 4 模型/信息置信度拆分执行层

## 范围

本次只修改参考轨迹的执行时钟与工程日志。Stage 1–4 已有控制器、积分估计器、
Human-space MPC、底层笛卡尔控制、刚性袖带合力/合矩边界、传感模型、增益、ROM、
机器人限制和 `200 N` 袖带平移力限制均未修改。未实现 tube MPC。

## 置信度拆分

执行层现在发布两个相互独立的信号：

1. **模型置信度**：当前 retained `last_valid` 几何与动力学模型是否有效。几何模型
   必须已经至少接受过一次更新、参数有限且长度为正；动力学模型必须已经至少接受
   过一次更新、参数有限且质量矩阵保持正定。候选更新被拒绝时，估计器继续保留
   `last_valid`，因此不会自动降低模型置信度。
2. **信息置信度**：最新数据是否具有足够秩、可接受的条件数、有限残差与有限协方差。
   它用于日志与解释估计器更新机会，不参与速度缩放。

执行速度只使用组合模型置信度。原始二值模型置信度先经过一阶低通，再进入滞回器：

```text
低通时间常数              0.75 s
进入高置信度阈值          0.75
退出高置信度阈值          0.25
低置信度速度              0.50
名义速度                  1.00
速度恢复率                0.25 /s
速度降低率                1.00 /s
```

这些值在工程对比之前固定，结果出来后未调参。速度始终不超过名义速度。

## 测试

新增/更新测试覆盖：

- 模型置信度低通后才恢复名义速度；
- 候选更新被拒绝但 current model 有效时不降速；
- 信息置信度变化不直接影响执行速度；
- 短暂模型置信度下降不会越过滞回退出阈值；
- 固定速度模式保持 `1.0`；

## 完成性分析

轨迹完成性得到明确改善。旧逻辑把候选拒绝等同于模型失效，在 `32 s` 内仅到达
参考相位 `18.039 s`；新逻辑在 `26.845 s` 完成完整参考轨迹，比固定速度慢
`3.845 s`，但不再因后续候选拒绝反复回到最低速度。新运行结束时，最新动力学
候选仍因 `bound_hit` 被拒绝，但 current `last_valid` 模型置信度、滤波后执行置信度
和速度比例均保持为 `1.0`，符合设计目标。

自适应组跟踪 RMSE 较低，但峰值袖带力从 `117.29 N` 略升至 `117.95 N`；单次理想
传感工程运行不足以证明性能或安全优势。可支持的结论仅为：**模型/信息置信度拆分
消除了候选拒绝导致的过度降速，并在相同 32 s 上限内恢复了完整轨迹执行。**

authoritative evidence。
