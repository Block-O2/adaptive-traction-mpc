# Stage 4 approved one-shot evidence

This directory contains the two seven-second population-prior cold-start
checks and the single approved 23-second high-flexion Adaptive MPC execution.
The `high_flexion_one_shot_adaptive.json` and matching compressed trace are the
authoritative run pair. `run_summary.json` records that the nominal and
registered perturbed cold starts were mechanically viable before the full run.

No result in this directory is a clinical safety or comfort claim.
